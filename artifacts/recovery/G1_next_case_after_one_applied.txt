2. VULNERABILITY ANALYSIS & FAIL-CLOSED HAZARD
--------------------------------------------------------------------------------
- Trigger Conditions:
  1. Invoking cscape_compile_project(project_name=".") or project_name="./" or project_name=".\\"
  2. Invoking cscape_compile_project(project_name="../../escape") or project_name="../outside"
  3. Invoking cscape_compile_project(project_name=str(uncontained_dir)) where uncontained_dir
     is an arbitrary disk directory lacking authentic Cscape project files (.csp, .cpj, cscape_project.json).
- Flaw in Previous Behavior:
  1. When project_name was supplied, cscape_compile_project executed:
         cand_p = Path(project_name)
         if cand_p.is_dir():
             proj_dir = cand_p.resolve()
  2. For project_name=".", cand_p.is_dir() evaluated to True for the current working directory,
     allowing compilation of arbitrary workspace folders rather than managed Cscape projects.
  3. Paths containing traversal sequences (e.g., "../../escape") or relative slash directory
     references ("./", ".\\") bypassed SafetyGuard.validate_project_name() whenever they
     resolved to existing directories.
  4. Any arbitrary folder with a pous/ subfolder was treated as a genuine Cscape project,
     even if it had no .csp, .cpj, or cscape_project.json manifest, violating fail-closed
     container integrity.
