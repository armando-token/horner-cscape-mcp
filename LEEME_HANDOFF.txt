3. PROCEDIMIENTO SEGURO DE GUARDADO ("SAVE AS WORKAROUND")
================================================================================
IMPORTANTE: Para evitar el diálogo "Failed to save document." causado por bloqueos
de archivo (ERROR_SHARING_VIOLATION = 32) o desincronización de streams CFBF:
1. No use Ctrl+S directamente sobre proyectos que hayan sido modificados externamente por scripts.
2. Utilice siempre "Save As" (ID_FILE_SAVEAS = 57604) indicando una ruta absoluta y versión limpia.
3. Si aparece la confirmación de sobrescritura, confirme con "Yes".
4. Verifique la validez del archivo resultante mediante is_valid_cfbf() post-guardado.

4. PROCEDIMIENTO PARA EL INGENIERO EN CAMPO (COMISIONAMIENTO MANUAL P7)
================================================================================
1. Abra Cscape 10.2 manualmente.
2. Abra el proyecto: File -> Open -> TankLevel_P5_Dedicated.csp.
3. Presione Program -> Error Check (Ctrl+F8). Confirme: "No error detected" (0 errores, 0 warnings).
4. Conecte el cable USB Mini-B a la OCS XL4 Prime.
5. Seleccione Controller -> Communication... y confirme la conexión (Node 253).
6. Seleccione Controller -> Download (Ctrl+F9) y marque Logic, Hardware, Protocols.
7. Al finalizar la descarga, pase la controladora a RUN y verifique en Data Watch que %AI1
   reciba la telemetría y %R1 escale correctamente a 0.0..100.0%.
8. Para detalles completos, consulte P7_MANUAL_COMMISSIONING_PROCEDURE.md.
