2. VULNERABILITY ANALYSIS & FAIL-CLOSED HAZARD
--------------------------------------------------------------------------------
- Trigger Conditions:
  1. Invoking cscape_insert_st(..., target_project_path="path/to/ghost_dir") or project_path
     pointing to a non-existent directory.
  2. Invoking cscape_insert_st(..., target_project_path="   ") with whitespace string.
- Flaw in Previous Behavior:
  1. When effective_path was provided and syntax_valid was True, cscape_insert_st executed:
         p_dir = Path(effective_path).resolve()
         pous_dir = p_dir / "pous"
         pous_dir.mkdir(parents=True, exist_ok=True)
         pou_file = pous_dir / f"{clean_pou_name}.st"
         pou_file.write_text(st_code, encoding="utf-8")
     It then returned status: "success", success: True, is_staged: True.
  2. If target_project_path pointed to a non-existent directory, pous_dir.mkdir(parents=True)
     created the directory tree out of thin air, generating spurious unmanaged directories
     and claiming successful staging on ghost projects.
  3. If target_project_path was whitespace (e.g. "   "), Path("   ").resolve() resolved to
     the active workspace root (C:\Users\ArmandoSilva), creating a spurious pous/ folder
     in the repository root!
